# Threat Model Folder

This folder mirrors the structure expected by the course rubric:

- `AssetInventory.md` — assets in scope and their security objectives.
- `ThreatModel.md` — STRIDE threats per component with risk reasoning and links to the exploitation findings.
- `ThreatModel.tm7` — Microsoft Threat Modeling Tool file. Generated by `scripts/generate_threat_model_tm7.py`; carries the project metadata, assumptions, external dependencies, and the 15 STRIDE threats (T1–T15) that match `ThreatModel.md`. The authoritative data-flow diagram lives in `ThreatModel.md` (Mermaid); the `.tm7` is provided for reviewers who prefer to open the file in MS TMT.

To regenerate the `.tm7` after editing threats in `ThreatModel.md`, update the `THREATS` list in `scripts/generate_threat_model_tm7.py` and re-run it.
